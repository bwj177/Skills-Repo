# Skills-Repo

个人 Skills 积累仓库，收录自建和精选的第三方 Claude Code Skills。

## 目录结构

```
├── own/                    # 自己构造的 skills
│   ├── doc-drawing-ppt/    # 写文档、画图、PPT 类
│   ├── self-evolution-harness/  # 自我进化、harness 相关
│   ├── code-efficiency/    # Code 提效类
│   ├── devops-infra/       # DevOps、基础设施类
│   └── other/              # 其他
│
└── third-party/            # 第三方好用的 skills
    ├── doc-drawing-ppt/    # 写文档、画图、PPT 类
    ├── self-evolution-harness/  # 自我进化、harness 相关
    ├── code-efficiency/    # Code 提效类
    ├── devops-infra/       # DevOps、基础设施类
    └── other/              # 其他
```

## 分类说明

| 分类 | 说明 |
|------|------|
| doc-drawing-ppt | 文档撰写、图表绘制、PPT 生成等 |
| self-evolution-harness | Skill 自进化、Claude Code harness 配置、hooks、settings 等 |
| code-efficiency | 代码生成、重构、review、debug 等开发提效 |
| devops-infra | 部署、CI/CD、监控、日志等运维基础设施 |
| other | 未归类的 skills |
